# instagram-analysis
## Dataset

This project uses an Instagram relational dataset containing users,
photos, likes, comments, follows, hashtags and photo-tag mappings.

Dataset source:

https://www.kaggle.com/datasets/bhanupratapbiswas/instgram

The raw dataset is not included in this repository. Download the data
from Kaggle and place the CSV files in the appropriate input directory
before running the notebook.
